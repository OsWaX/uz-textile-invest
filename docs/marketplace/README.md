# Маркетплейс нового поколения — материалы проекта

Комплект документов для создания торговой интернет-площадки, построенной на
двух отличиях от существующих маркетплейсов: **у оператора нет складов**
(товар всегда находится у продавца) и **деньги покупателя поступают продавцу
напрямую** через расщепление платежа, а не накапливаются на счетах оператора.

| Документ | Содержание |
|---|---|
| [research.md](research.md) | Аналитический обзор Amazon, Wildberries, Ozon, Uzum Market, eBay, Etsy, Temu: сильные и слабые стороны, сводная матрица «боль → требование», источники |
| [tz.md](tz.md) | Полное техническое задание версии 1.0: принципы, роли, финансовый контур, логистика, функциональные и нефункциональные требования, архитектура, модель данных, API, правовые требования РУз, этапы, приёмка, риски, приложения |

| [ТЗ. Маркетплейс нового поколения.docx](%D0%A2%D0%97.%20%D0%9C%D0%B0%D1%80%D0%BA%D0%B5%D1%82%D0%BF%D0%BB%D0%B5%D0%B9%D1%81%20%D0%BD%D0%BE%D0%B2%D0%BE%D0%B3%D0%BE%20%D0%BF%D0%BE%D0%BA%D0%BE%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F.docx) | То же ТЗ в формате Microsoft Word: титульный лист, автоматическое оглавление, колонтитулы, таблицы |

Файл Word собирается из `tz.md` командой:

```bash
npm install docx
node scripts/md2docx.js docs/marketplace/tz.md "docs/marketplace/ТЗ. Маркетплейс нового поколения.docx"
```

При первом открытии в Word оглавление следует обновить (выделить и нажать F9).

Порядок чтения: сначала `research.md` — он объясняет, почему в ТЗ приняты
именно такие решения, затем `tz.md`.

Материалы не относятся к порталу Проектного офиса, размещённому в корне
репозитория, и хранятся отдельно.
