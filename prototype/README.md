# Прототип маркетплейса «Rasta»

Работающий прототип витрины и кабинетов, собранный по
[ТЗ «Маркетплейс нового поколения» v1.0](../docs/marketplace/tz.md).
Опубликован как Artifact: <https://claude.ai/code/artifact/a3a88395-0f1b-4178-a6e4-f8f9b453d44b>

Один файл `rasta.html` — без сборки и без внешних зависимостей, кроме шрифтов
Google Fonts. Данные демонстрационные и хранятся в `localStorage` браузера,
поэтому у каждого посетителя своя копия: чужие заказы и товары не видны.

## Что реализовано

| Раздел ТЗ | Реализация в прототипе |
|---|---|
| П1 — складов оператора нет | В системе нет сущности склада оператора: остаток и отгрузка — у продавца |
| П2, §6 — расщепление платежа | Расчёт по §19.3 ТЗ; «полоса денег» показывается в карточке, корзине, чеке и кабинете |
| §6.2 — режимы расчёта | Защищённый (раскрытие после подтверждения получения) и мгновенное расщепление для продавцов с рейтингом ≥ 4,6 |
| §7 — логистика | Пять моделей доставки, выбор перевозчика в один клик, накладная, трекинг, срок и цена по городу покупателя |
| §8.3 — ранжирование | Опубликованная формула, кнопка «Почему этот товар выше?» с разложением по факторам |
| §8.4 — мультипродавцовый заказ | Корзина разделяется по продавцам: своя доставка, свой срок, своё расщепление |
| §8.7 — споры | Состязательная процедура из четырёх шагов, доказательства, решение и возврат с пропорциональной комиссией |
| §8.10 — кабинет продавца | Показатели, товары с калькулятором дохода, заказы (подтверждение, фиксация вложения, передача перевозчику), реестр операций, рейтинг |
| §15.3 — публичная отчётность | Раздел «Прозрачность»: версии тарифов, квартальные показатели, сравнение скорости выплат |
| §9.4 — локализация | Узбекский (латиница), русский, английский; светлая и тёмная темы |

## Как открыть локально

```bash
python3 -m http.server 8000 --directory prototype
# затем http://localhost:8000/rasta.html
```

Кнопка «Сбросить демо» в верхней полосе возвращает исходные данные.
